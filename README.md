# AI/ML Trainee Assessment

This repository contains my work for the AI/ML Trainee Assessment. It includes Python programming tasks, API data retrieval, data visualization, database operations, and project documentation covering AI/ML applications, LLM chatbot architecture, and vector databases.

## Repository Structure

The assessment is organized into two main sections.

### Assessment 1 — Python Programming and Projects

| Task | Description | Technologies |
|---|---|---|
| [Task 1 — API Data Retrieval](./Assessment-1/Task-1-API-Retrieval/) | Fetch book information from the Open Library API, process the response, and store records in SQLite. | Python, Requests, SQLite |
| [Task 2 — Data Visualization](./Assessment-1/Task-2-Data-Visualization/) | Retrieve student scores from a local API, calculate averages, and generate a bar chart. | Python, Flask, Pandas, Matplotlib |
| [Task 3 — CSV to SQLite](./Assessment-1/Task-3-CSV-to-SQLite/) | Validate user records from a CSV file and import them into an SQLite database. | Python, CSV, SQLite |
| [Task 4 — CareerIQ](./Assessment-1/Task-4-Python-Code/) | Showcase an AI-powered career intelligence platform with job matching, skill-gap analysis, RAG, and an AI assistant. | Python, FastAPI, NLP/ML, PostgreSQL, React |
| [Task 5 — FlowSync Database Code](./Assessment-1/Task-5-Database-Code/) | Document the database schema and migration code for an employee productivity platform. | PostgreSQL, Flyway, Java, Spring Boot |

### Assessment 2 — AI and LLM Concepts
